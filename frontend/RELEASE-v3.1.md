# v3.1: больше вариантов, подробности отелей

- Деморежим: 6 направлений и 4 отеля вместо 3 и 2.
- «Подробнее» у отеля теперь открывает диалог с деталями. Закрытие через крестик, Escape, щелчок вне окна или «Вернуться к вариантам».
- Старое демосостояние из v3 не загружается, чтобы не оставалось старое количество карточек; новый ключ сессии v3.1.
- **Важно:** цены, оценки, погода и отели в деморежиме полностью синтетические. Фронтенд не делает запросы в live Data в деморежиме.
- API, SSE и маршруты Next.js не менялись.

## Установка

Полный архив содержит корневую папку `frontend/` со своим package.json. Положить папку в корень проекта, объединить файлы. Сохранить свой `.env.local`, если есть. Далее в frontend/: `npm install` и `npm run dev -- -p 3001`.

## Проверка кнопки «Подробнее»
1. Открыть демо, перейти в «Направления», выбрать любой город.
2. На странице «Подбор поездки» нажать «Подробнее» у любого отеля.
3. Откроется модальное окно с фактами, ценами, плюсами и рисками.
4. Закрыть кнопкой, нажатием вне окна или Escape. Диалог не отправляет лишнее сообщение агенту.
